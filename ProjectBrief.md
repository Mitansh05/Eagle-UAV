# Eagle

**Project Type:** Fixed Wing UAV | Aerospace Engineering  
**Project Status:** Planning and Research  
**V1**

## 1. Project Overview

My ultimate goal for this project is to design and build my unmanned aerial vehicle (UAV) to get more experience in aerospace engineering. Additionally, through this project I want to learn how an aircraft works, how different systems work together, and how to build and test the final aircraft.

## 2. Project Goals

- Learn the basics of aerodynamics, lift, drag, and stability.
- Design an aircraft using CAD.
- Understand the basics of propulsion, electronics, and flight controls.
- Build an affordable and lightweight prototype.
- Test the aircraft, document the result, and improve.

## 3. Initial Design

I want to start with a small electric fixed wing aircraft. Now, I chose this design because it will help me understand the fundamentals of the most common aircraft type.

As of right now, I am looking forward for the first version of the UAV to be able to be stable, manual flight controls, have estimated flight time, and possibly even autonomous orbiting with a live GPS loction.

## 4. Current Plan

1. **Research:** Learn the basics about aerodynamics and fixed wing aircraft design.
2. **Design:** Create basic sketches and a CAD model.
3. **Planning:** Choose suitable materials and components based on the design and the budget.
4. **Building:** Build the prototype and assemble all the systems.
5. **Testing:** Test the prototype in the real world and document.
6. **Improvement:** Improve any improvements that is need, from the previous step.

## 5. Budget and Safety

I will soon come up with a realistic budget for this project before purchasing any components. All the testing session will be conducted with proper procedure.

## 6. Criteria

This project will be considered successful when I have design and built a functioning UAV with stable flight and when I have meet more of the goals.

## 7. Next Step

I will create a list of the components I plan to use as the foundation for my design. I will consider factors such as cost, weight, compatibility, and availability before making my final selections.
